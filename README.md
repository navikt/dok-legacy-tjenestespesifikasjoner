# dok-legacy-tjenestespesifikasjoner
SOAP-grensesnittspakker for Team Dokumentløsninger

- `behandledokumentredigering-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`
- `dok-brevdata-felles` - XSD til JAXB-objekter for `regoppslag` (`melosys-brevpakke`, `gosys-brevpakke`, `brevpakke-deployer`)
- `dok-domene-arkiverdokumentproduksjon-v1-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`, `dokopp`, `dokarkiv`
- `dok-domene-dokumentproduksjoninfo-v1-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`, `dokarkiv`
- `dok-melding-virksomhet-dokdistfordeling` - XSD til JAXB-objekter for `dokprod` og `dokdist`-appene
- `dok-melding-virksomhet-dokumentproduksjon` - XSD til JAXB-objekter for `dokprod`
- `dok-nav-dokumentproduksjon-v3-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`, `ezbrev-backend` (`melosys-api`)
- `dok-nav-fim-dokumentproduksjon-v2-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`
- `dokumentbehandling-tjenestespesifikasjon` - WSDL til JAXB-objekter for `brevserver-nais`, `brevklient (`bidrag-bisys`, `bidrag-testdata`, `bidrag-dokument-arkivering`, `bidrag-dokument-journalpost`)
- `loggmottak-tjenestespesifikasjon` - WSDL til JAX-objekter for `brevserver-nais`, `brevklient`
- `metaforce-general-service-tjenestespesifikasjon` - WSDL til JAXB-objekter for `dokprod`, `foerstesidegenerator`
- `metaforce-metawrite-service-tjenestespesifikasjon` - WSDL til JAXB-objekter for `ezbrev-backend`
- `nav-journal-tjenestespesifikasjon` - WSDL til JAXB-objekter for `brevserver-nais`, `joark`
- `nav-journalbehandling-tjenestespesifikasjon` - WSDL til JAXB-objekter for `brevserver-nais`, `joark`
- `nav-varsel-inn` - XSD til JAXB-objekter for `varsel2`
- `nav-virksomhet-dokumentstatusoppdatert-v1-meldingsdefinisjon` - XSD til JAXB-objekter for `dokprod`
