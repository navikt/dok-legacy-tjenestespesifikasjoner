# dok-legacy-tjenestespesifikasjoner
SOAP grensesnitt pakker for Team Dokumentløsninger

- `metaforce-metawrite-service-tjenestespesifikasjon` - WSDL til JAXB objekter for `ezbrev-backend`
- `metaforce-general-service-tjenestespesifikasjon` - WSDL til JAXB objekter for `dokprod`, `foerstesidegenerator`
- `behandledokumentredigering-tjenestespesifikasjon` - WSDL til JAXB objekter for `dokprod`
- `dokumentbehandling-tjenestespesifikasjon` - WSDL til JAXB objekter for `brevserver-nais`
- `loggmottak-tjenestespesifikasjon` - WSDL til JAXB objekter for `brevserver-nais`
- `nav-journalbehandling-tjenestespesifikasjon` - WSDL til JAXB objekter for `brevserver-nais`
- `nav-journal-tjenestespesifikasjon` - WSDL til JAXB objekter for `brevserver-nais`
- `dok-brevdata-felles` - XSD til JAXB objekter for `regoppslag`
- `nav-fim-dokumentproduksjon-v2-tjenestespesifikasjon` - WSDL til JAXB objekter for `dokprod`
- `dok-nav-dokumentproduksjon-v3-tjenestespesifikasjon` - WSDL til JAXB objekter for `dokprod`, `ezbrev-backend`
- `nav-virksomhet-dokumentstatusoppdatert-v1-meldingsdefinisjon` - XSD til JAXB objekter for `dokprod`
- `melding-virksomhet-dokdistfordeling` - XSD til JAXB objekter for `dokprod` og `dokdist`-appene
